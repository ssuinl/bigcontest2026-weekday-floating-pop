# 빅콘테스트 요일별 유동인구 분석

2026 빅콘테스트 AI데이터 분석 분야 「기후 위기에 따른 취약 상권 영향 분석」 · 2인 팀 · 2026.10

팀 프로젝트 중 제가 맡은 분석을 정리했습니다. 맡은 부분은 제공 데이터 탐색, 요일별 유동인구 분석, 시각화입니다.

## 분석 목적
강남구와 춘천시의 카드 매출이 날씨(비·폭염 등)에 얼마나 민감한지 보고, 기후에 취약한 상권을 찾는 것이 팀 과제였습니다. 그 전 단계로 제공 데이터의 구조와 함정을 먼저 확인하고, 두 지역의 **요일별 유동인구 패턴**을 비교해 거주지·업무지구·관광지 성격을 파악하는 것이 제 목표였습니다.

## 데이터
| 데이터 | 단위 | 기간 |
|---|---|---|
| SKT 유동인구 (성·연령별 / 시간대별 / 요일별) | 50m 격자, 월 | 2025.7~12 |
| 신한카드 결제 (데이터1) | 시군구 × 업종 × 성·연령 × 시간대, 일 | 2025.7~12 |
| 기상청 관측 (외부 공공데이터) | 일 | 같은 기간 |

## 분석 과정
확인된 사실, 관찰 결과, 가설을 구분해 기록했습니다.
- 파생변수 생성, 행 삭제, 결측 대체 같은 데이터 변경은 팀에서 변경 내용을 확인한 뒤에만 적용했습니다.
- 같은 집계를 두 번 따로 구현해 숫자가 일치하는지 교차 검증했습니다 (A2 집계표 ↔ A3 구현, 오차 1e-6 이내).

| 단계 | 내용 |
|---|---|
| EDA (`01_provided_data_eda.ipynb`) | 카드·유동인구 데이터의 의문점 정리: 5건 미만 칸 처리 방식, 'ZZ_나머지' 업종 급등, 법인카드 비중, 비수도권 고객 결제, BLOCK_CD 코드 구조, 12월 파일 중복 |
| A3 (`src/a3_weekday_analysis.py`) | 지역 × 월 × 요일별 합계·평균·중앙값, 격자 분포 분위수(Q1~P95, 0값 비율) |
| A4 | 6개월 공통 격자 112,708개만으로 다시 집계해서, 결과가 격자 수 변동 때문이 아닌지 확인 |

## 분석 결과
- **강남:** 토요일은 격자 분포의 아래·가운데가 올라가고 위쪽은 내려갑니다 (6개월 모두 같음).
  - 예: 7월 토요일 중앙값 129.5 vs 평일 108.9~114.2 / P95 1,859 vs 평일 2,414~2,598
  - 그래서 합계·평균과 중앙값이 반대 방향으로 움직였습니다.
- **춘천:** 강남과 반대 모양입니다. 주말에 0값 격자 비율이 오르고(6.0~8.5%, 평일 2.0~3.9%) 상위 분위는 커집니다.
- **이례적인 날:** 강남 8월 금요일, 10월 월요일, 12월 목요일은 공휴일과 겹쳐 값이 낮았습니다. 이 해석은 HYPOTHESIS로만 남겼습니다.
- **데이터 해석 시 주의점:** 시간대 표의 24시간 합이 하루 총량과 같아서, 시간 값은 체류 인구가 아니라 하루 유동을 나눈 값입니다. 강남 음식점 매출의 40% 이상이 법인카드라 '법인 제외'는 재검토가 필요했습니다.

팀 최종 결과물은 업종별 기후 민감도를 기상 예보와 연결하는 기후 취약 상권 조기경보 시스템 제안이었고, 대회 결과는 탈락이었습니다.
